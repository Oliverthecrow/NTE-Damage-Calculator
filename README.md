MV based:
this is the most simple one, mainly you just need to know what is DMG% versus true mult, and what is def reduction versus ignore.

Break based:
this is probably the hardest one, lets start with what the hell "Universal Ignore" is there for, pretty much set effects like Lost Radiance, and Diablos Do not work when they are
not the character breaking the enemy, but there are things like awakenings, or Iroi's def ignore, that DO work for off field characters, you will have to know what ones work, and
which ones dont unfortunately. besides that you will have to know each of the characters resistances for any given enemy, and find out the enemy max break.

Reaction based:
Reaction Ownership will automatically be handled for you, just remember for enemy
res reduction to only account for res reduction that applies to the esper matching
the owenr, OR mental dmg for nova if applicable.
